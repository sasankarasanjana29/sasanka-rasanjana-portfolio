# Sasanka Rasanjana, portfolio

My UX/UI and product design portfolio: case studies (TrustBank, VELA, Keells, ZestBowls) and the apps I designed and built (Cloudia, Pouch, Fretbelly).

It is a **static site**: plain HTML, CSS and a little JavaScript, no framework and no build step.

| File | Page |
|---|---|
| `index.html` | Home |
| `work/*.html` | One page per case study and app |
| `styles.css`, `main.js` | Shared styles and interactions |
| `img/` | Compressed WebP images |
| `Sasanka_Rasanjana_CV.pdf` | Resume |

## Preview locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
